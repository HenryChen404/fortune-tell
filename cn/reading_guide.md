# 解盘规则指南

由主 SKILL.md 在进入解盘时通过 Read 工具加载。**每次解盘必须严格遵守以下规则。**

---

## Step 1: 准备

1. 读取 `$REFS/birth-info.md` 确认命主身份
2. 根据命主的问题判断适用体系（第一法则：至少 2 个体系适用才继续）
   - 仅 1 个体系适用时，告知局限："这个问题我只能从[体系名]来分析，缺少第二个体系交叉验证，结论可靠度有限。我可以先给你一个初步参考，但请注意这没有经过多体系确认。"
3. **只读取适用体系的命盘文件和验盘档案**（如问八字相关 → 读 `bazi.md` + `bazi_calibration.md`）
4. 验盘档案不存在 → 提示先完成验盘
5. 不理解命主意图 → **先提问，不强行回答**

## Step 2: 逐体系分析

对每个适用体系，按以下规则应用验盘数据：

### 读取基准线

每个验盘档案头部有 `## 命主基准线` 段（如果存在），在逐体系分析之前先读取。基准线影响后续所有解盘的措辞和强度判断。

### 方向选择（用哪个方向）

| 验盘结果 | 处理 |
|---------|------|
| `confirmed` | 按确认方向解盘，高权重 |
| `confirmed_form` | 按**已锁定的显化形式**解盘，高权重。未来同类原局象出现时，优先映射到此显化形式 |
| `confirmed_scaled` | 按确认方向解盘，但**按基准线调整强度措辞**（见下方基准线修正） |
| `contradicted` | 降权，按下方矛盾处理规则 |
| `tier2_skipped` | 用先天强弱，方向不锁定，中置信度；强者注明"未经验证" |
| `uncertain` | 低置信度，探索性措辞 |
| 同一原局象多时期 | 综合分析：多时期 confirmed → 提升置信度；结果不一致 → 分时期讨论 |

### 五行缺失的大运/流年补充判定

命局五行缺失不等于该功能永久缺失。大运和流年可以补充缺失五行：

| 场景 | 处理 |
|------|------|
| 命局缺某五行 + 大运/流年带入该五行 | 不可直接判定为"功能缺失"——大运补充可能恢复该功能 |
| 命局缺某五行 + 大运/流年也不带入 | 可判定该功能在此时期确实受限 |
| 命局某五行过旺 + 大运/流年继续加强 | 过旺问题加剧，可作为负面信号 |

**特别注意**：缺失资源元素（印星）≠ 必然衰退。流年补充印星 = 该年获得资源/支持。不可仅凭命局缺失元素做负面预测而忽略大运/流年的补充作用。

### 篇幅和语气（由来源原局象的先天强弱决定，经基准线修正）

| 先天强弱 | 篇幅 | 语气 |
|---------|------|------|
| 强 | 核心发现，2-3 句 | "你命盘中这个特征很明显……" |
| 中 | 辅助信息，1-2 句 | "从命盘来看，这方面有一定倾向……" |
| 弱 | 命主问及时才提，1 句 | "有一个比较微弱的信号……" |

**基准线修正**（如果 `## 命主基准线` 存在）：

| 组合 | 修正 |
|------|------|
| 先天强弱强 + 强度基线偏弱 | 保持核心发现地位，但措辞降半级（"很明显" → "有一定影响"） |
| 先天强弱弱 + 强度基线偏强 | 提升关注度（"微弱信号" → "值得注意"） |
| 涉及六亲 + 六亲缓冲高 | 用更保守的措辞，优先映射到非六亲领域（如资产、情绪） |
| 显化倾向偏内在心理 | 外部事件预测降半级，内在心理体验预测升半级 |

### 措辞确定性（由置信度决定）

| 置信度 | 措辞 |
|-------|------|
| 高 | 直接断言："你的命盘显示……" |
| 中 | 适度限定："从目前的信息来看……" |
| 低 | 探索性："有一个有意思的信号，但我还不太确定……" |

### contradicted 状态的矛盾处理

| 场景 | 处理 |
|------|------|
| 解盘过去 | 信任命主体验，不用理论强行解释 |
| 解盘当前 | 呈现矛盾："理论上很强，但之前了解来看不太明显，可能以不易察觉的方式运作" |
| 预测未来 | 保守："有理论信号但过去未印证，我持谨慎态度" |
| 部分时期 confirmed + 部分 contradicted | 说明显化有时期性，区分讨论 |
| 时辰校正前的 contradicted 数据 | 参考价值极低，基本忽略 |

## Step 2.5: 极性判定（正面 vs 负面）

识别出某领域有活跃能量后，必须判定其极性。不得默认正面或用"调整/转型"回避判定。

### 负面极性信号（任一体系出现 ≥2 条 → 该维度判定为负面）

| 体系 | 负面信号 |
|------|---------|
| 八字 | 忌神当令、伤官见官、比劫夺财、用神被克合、刑冲破害 |
| 紫微 | 化忌入该宫位、主星陷落、煞星（火铃羊陀）聚集、空劫夹 |
| 西洋 | 硬相位（square/opposition）主导、逆行行星介入、12/8/6宫集中 |

### 正面极性信号（任一体系出现 ≥2 条 → 该维度判定为正面）

| 体系 | 正面信号 |
|------|---------|
| 八字 | 用神得力、食神制杀、财官印顺生、天乙贵人 |
| 紫微 | 化禄/化权/化科入该宫位、主星庙旺、左辅右弼/天魁天钺 |
| 西洋 | 柔和相位（trine/sextile）主导、Jupiter正面参与、北交点相关 |

### 极性冲突处理

| 场景 | 处理 |
|------|------|
| 正负信号均 ≥2 条 | 判定为"动荡"：明确说"这个领域会很活跃，正面和负面因素并存" |
| 负面信号 ≥2、正面 <2 | 判定为负面，用明确负面措辞 |
| 正面信号 ≥2、负面 <2 | 判定为正面，用明确正面措辞 |
| 两边均 <2 | 信号不足，该维度不输出 |
| 三体系极性不一致 | 不做多数投票——明确列出各体系判断及分歧，标注为"体系分歧"置信度 |

**极性判定置信度**：信号 ≥3 条且方向一致 → 强信号；信号 =2 条 → 弱信号（措辞需保留余地）

**禁止**：用"调整期""过渡""转型"等中性词回避极性判定。这些词仅在极性真正模糊（正负均≥2）时使用。

### 婚恋极性特别规则

婚恋维度不得使用"调整""磨合""需要沟通"作为默认预测。必须明确判定方向。

**核心原则：强度 ≠ 负面极性。** 关系宫的高强度信号（化忌、Venus硬相位、七杀等）意味着"关系领域有重大事件"，不等于"关系遇到困难"。结婚、生子、新恋情同样是高强度事件。

**婚恋极性判定两步法：**

**Step A — 判定强度：** 关系宫/维度有 ≥2 条活跃信号 → 高强度期（不立即判定极性）

**Step B — 判定极性方向：**

| 信号组合 | 极性 | 说明 |
|---------|------|------|
| 夫妻宫化忌 + 煞星（火铃羊陀）≥1 + 无正面对冲 | → 负面：分手/离婚/关系终结 | 忌+煞 = 破坏性组合 |
| 夫妻宫化忌（无煞星加重） | → **高强度，方向待定** | 忌 = 在意/执着，不等于破坏 |
| 夫妻宫化禄/化权 + 主星庙旺 | → 正面：订婚/结婚/关系深化 | 正面进展 |
| Venus 硬相位（square/opposition）to outer planets | → **高强度，方向待定** | 转化性能量，不默认负面 |
| 多体系关系宫均高强度 + 生活其他维度（事业/财务）稳定 | → 正面（除非有明确分离/终结信号） | 稳定基础上的关系发展 |
| 多体系关系宫均高强度 + 生活其他维度也动荡 | → 动荡 | 全面不稳定 |
| 七杀/伤官在大运 + 夫妻宫活跃 | → 高强度，需看整体生活状态 | 七杀压力不等于婚姻压力 |
| Saturn 过境 7th house | → 关系考验期/分离压力 | |
| Jupiter 过境 7th house | → 关系扩展期/新恋情可能 | |

**Fallback 规则：** 当极性"方向待定"时，默认输出"关系高度活跃期——可能出现重大正面或负面事件"，**不得**默认为 TURBULENT 或 NEGATIVE。模型必须主动寻找明确的负面证据才能判定负面。

### 健康预测门槛

健康维度有特殊的证据门槛。不可证伪的健康"建议"不是预测。

#### 不输出（以下信号单独出现不构成健康预测）

- 仅基于年龄的推断（"60岁需关注心血管"）
- 仅基于五行缺失的推断（"无金注意呼吸系统"）
- 仅基于单体系的弱信号
- 基于职业的同义反复（"运动员注意关节"）

#### 可输出（需满足以下任一）

| 条件 | 输出方式 |
|------|---------|
| 大限/大运走入疾厄宫 + 该宫有负面星曜 | 明确预测健康事件 |
| ≥2 个体系的健康信号指向同一系统/器官 | 跨体系确认后预测 |
| 流年冲克本命健康敏感点 + 行运同步激活 | 限时预测（注明时间窗口） |

**健康预测附加条件**（满足上述门槛后还需满足）：
- 必须指出具体健康方向（心血管/关节/消化/呼吸 等），不可泛说"健康问题"或"注意健康"
- 如果只能说"需要注意健康"→ 不输出（不可证伪）
- 他人健康问题（如子女、配偶的健康）不归入本人健康维度
- **维度配额优先级**：如果3个维度配额已被更高置信度的维度填满，健康维度应被优先舍弃（当前数据表明健康维度验证价值最低）

不满足门槛 → 不输出健康维度，而非用"注意保养"等不可证伪的措辞填充。

### 危机事件识别（实验性规则）

以下信号组合指向突发危机事件（而非渐变趋势），应以"可能发生突发事件"的方式预测，而非用"需要注意"淡化。标记为实验性规则，需后续盲测验证效果。

| 组合 | 危机类型 |
|------|---------|
| 福德宫化忌 + 煞星 + Mars-Neptune 硬相位 | 成瘾/药物/酒精相关事件 |
| 伤官见官 + 比劫旺 + 流年冲动 | 冲动行为导致的法律/公众危机 |
| 12宫主星被流年外行星精确相位激活（≤1°）+ 本命12宫有行星 | 隐秘行为被迫曝光 |
| 疾厄宫化忌 + 煞星聚（≥2颗）+ 流年冲该宫 | 急性健康事件 |
| 廉贞化忌 + 天刑同宫或对宫 | 法律事件、诉讼、官非 |

## Step 3: 交叉比对

比较各体系对同一主题的结论（第二法则）：

| 体系一致性 | 验盘状态 | 处理 |
|-----------|---------|------|
| 全部一致 | 已验盘 | 核心发现，高置信度 |
| 全部一致 | 部分未验盘 | 核心发现，中置信度 |
| 多数一致 | 已验盘 | 辅助发现，中等措辞 |
| 多数一致 | 未验盘 | 相关时提及，保守措辞 |
| 少数一致 | — | 不输出 |
| 完全分歧 | — | 坦诚告知无法给出可靠结论 |

合并条目（来源 ≥ 2 个体系）confirmed → 跨体系一致性自动确认。

### 置信度上限规则

交叉比对后、输出前，对每个预测维度执行置信度校准：

**维度类型决定置信度上限**

| 维度类型 | 最高允许置信度 | 理由 |
|---------|-------------|------|
| 事业/创意 | High | 盲测验证命中率最高 |
| 财务/商业 | High | 盲测零误判率 |
| 婚恋/关系 | **Medium-High**（上限） | 系统性偏差未消除前不允许High |
| 健康/身体 | **Medium**（上限） | 验证价值极低 |

**HIGH 置信度必要条件**（全部满足才可标注 High）：
1. 3个体系极性方向一致
2. 无任何体系出现矛盾信号
3. 维度类型允许 High（见上表）
4. 每个体系至少有 2 条支持信号

### 不可证伪检查

输出前对每个预测执行以下检查，不通过的预测必须改写或删除：

| 检查项 | 不通过的例子 | 处理 |
|-------|------------|------|
| 可证伪性 | "需要注意健康" / "事业有调整" / "感情需要经营" | 改写为具体可验证预测或删除该维度 |
| 时间锚定 | "未来可能有变化" | 必须锚定到预测窗口内的具体时段 |
| 方向明确 | "可能有发展" | 必须说明是正面还是负面发展 |
| 非同义反复 | "运动员需关注伤病" / "老年人需注意身体" | 删除——常识不是命理预测 |

### 维度取舍规则

- 每个人最多预测 3-4 个维度（从最强信号的维度开始）
- 信号弱的维度：**不预测好过给出模糊预测**
- 星级 ≤ ★★★ 且无跨体系确认 → 该维度不输出

2. **拆解问题**为原子级子问题，逐个按以下结构输出：

- [ ] 基准线已读取（如存在）
- [ ] 篇幅/语气匹配先天强弱（经基准线修正）
- [ ] 措辞匹配置信度
- [ ] 未验盘条目：中置信度，强者注明未验证
- [ ] confirmed → 高权重

- [ ] confirmed_scaled → 按基准线调整强度措辞
