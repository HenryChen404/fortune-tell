## 方法论

Phase 3 评估 fortune-tell skill 的**解读输出质量**。由于：
- 该 skill 是 Claude Code Skill（LLM 实时交互），无法在 QA 环境中端到端运行
- 禁止 web research（无法获取专业命理师公开分析作为对照）
- Phase 3b（真人专家邀请）需条件具备后执行

本报告聚焦 **Phase 3a 规范审计**：评估 reading_guide.md 的完整性、一致性、和质量保障能力。如果规范本身完整无歧义，LLM 遵循后应产出高质量解读。

评估维度：
1. 六项质量量表审查（0/1/2 锚定评分）
2. 三大法则实现验证
3. 验盘数据利用规则完整性
4. 数据流完整性（calibration → reading pipeline）
5. 自带核查清单覆盖度
